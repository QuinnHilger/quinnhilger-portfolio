# Quinn Hilger's Portfolio

🚀 **[View Live Site](https://quinnhilger.github.io/quinnhilger-portfolio/)**

A personal portfolio website built with React, TypeScript, and Vite.

## Tech Stack

- **React 19** - UI framework
- **TypeScript** - Type safety
- **Vite** - Build tool
- **React Router** - Client-side routing
- **React Markdown** - Blog content rendering

## Development

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build

# Deploy to GitHub Pages
npm run deploy
```
